A personal Obsidian plugin that lets you right-click any block (heading section, paragraph, list) in the editor and instantly see semantically related blocks/files from your vault, powered by the Smart Connections embedding database.

## User Flow

1. User is editing a note in Obsidian
2. User selects text or places cursor within a block
3. User right-clicks → context menu shows **"See relevant connections"**
4. A sidebar panel opens showing ranked results (blocks or files, togglable)
5. Each result shows: title/path, score, preview snippet
6. User can click to navigate, hover-preview (Cmd/Ctrl), or copy the entire list
